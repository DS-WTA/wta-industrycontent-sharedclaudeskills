# WTA-industrycontent-claudeskills

Claude Code Plugins by DScott

## Installation

Add the marketplace to Claude Code:

```
/plugin marketplace add DS-WTA/wta-industrycontent-sharedclaudeskills
```

Install a specific plugin:

```
/plugin install example-plugin@WTA-industrycontent-claudeskills
```

## Plugins

- **example-plugin**: Example plugin demonstrating command structure

## Development

Run the linter to validate plugin structure:

```bash
make lint
```

Update plugin documentation and website:

```bash
make update
```
